# Music Player

Keyboard-controlled music player built with pygame.mixer.

Place `.mp3`, `.wav`, or `.ogg` files in the `music/` folder.

| Key | Action |
|-----|--------|
| P | Play current track |
| S | Stop playback |
| N | Next track |
| B | Previous track |
| Q / Esc | Quit |

Run: `python main.py`
